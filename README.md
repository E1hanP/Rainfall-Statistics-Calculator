# Rainfall-Statistics-Calculator
Simply checks how much rains will fall on each day based on the user's input
# Features
* Designed and implemented a modular C++ program to process and analyze yearly rainfall data for 12 months, calculating the total, average, highest, and lowest monthly rainfall.
* Utilized array traversal and conditional logic to efficiently determine the annual rainfall extremes and their corresponding month index.
* Incorporated robust input validation to ensure numerical integrity by rejecting negative values, demonstrating defensive programming practices.
